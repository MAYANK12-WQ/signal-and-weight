How a Model Learns — and How It Overreacts

A model is just a curve trying to match a cloud of points. Drag the complexity slider and watch the same 18 data points get fit by curves that are too simple, then too obedient.

Why this matters

Low degree ignores the pattern (underfitting). Very high degree memorizes the noise in these exact 18 points instead of the shape underneath (overfitting) — training error drops to near zero while error on new points climbs back up. The sweet spot is wherever test error is lowest, not where training error is lowest.

Exhibit 03 · often confusing

Inside a Neuron

A neuron multiplies each incoming number by a weight, adds them up, and squashes the result through an activation function. Drag the two inputs. Drag up or down directly on any connecting line to change its weight and watch every downstream neuron react.

Forward passactivation: sigmoid
Network output
–
What you're seeing

Every line is a weight; its thickness is the weight's size and its color shows the sign — teal strengthens, rust weakens. Every circle is a neuron; brighter fill means it fired more strongly. Training a network is nothing more than automatically adjusting every one of these weights until the output matches what you wanted — the same drag you just did by hand, done by gradient descent instead.

Breaking Language Into Pieces

Switch to subword mode and type a long or unusual word like "antidisestablishmentarianism" or a made-up one like "blorptastic". The model has never seen the whole word before, but it has seen small pieces of it — so it reads the piece it recognizes and reasons about the rest fragment by fragment, exactly like sounding out a word you've never read.

Exhibit 05 · often confusing

Meaning as Coordinates

Once text is tokens, each token gets converted into a list of numbers — a point in space — called an embedding. Words with related meaning end up near each other. Real embeddings use hundreds of numbers per word; this toy version uses two, so you can see it plotted directly. Click a word, or drag it somewhere new.

Toy embedding space (2 dimensions)click a point
Nearest neighbors
  • Select a word to compare
Why this matters

Nobody hand-writes these coordinates. A model learns them by reading huge amounts of text and noticing which words tend to appear in similar situations — "cat" and "dog" show up in similar sentences, so they drift close together, entirely on their own.

Exhibit 06 · the payoff

Putting It Together: Attention

This is how the ideas above combine inside something like GPT: tokenize the sentence, look up each token's embedding, then have every token compare itself to every other token to decide what to focus on. Click a word to see where it's looking.

Self-attention (simplified, 4-dimensional teaching model)
    Reading the picture

    Notice both "the"s get identical embeddings (same word, same fingerprint) but can still end up attending differently, because attention also depends on which other words are nearby. This is a simplified teaching version of the mechanism — a real transformer runs many attention "heads" in parallel across hundreds of dimensions. For a beautifully detailed, real-weights version of this exact idea, see the Transformer Explainer project, which inspired this exhibit.
